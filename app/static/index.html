可选「复位阈值」（仅 >、>=、<、<=）：首次满足原比较才命中，此后保持命中直到值到达复位边界 （高值触发：值 ≤ 复位值；低值触发：值 ≥ 复位值）；高值触发复位值须低于触发阈值，低值触发须高于。 采样有效期到期空档会清除命中状态，下一样本需重新触发。

计划维护

维护窗口为半开区间 [start, end)：评估时同设备重叠/相接窗口先合并，再从该设备参与规则的真值段中扣除； 中断会重置持续时长，窗口结束后重新累计确认。保存后自动重新评估。

采样有效期

按「设备 + 指标」配置正秒数有效期：样本值仅保持在 [采样时刻, min(下一样本时刻, 采样时刻+有效期, 数据终点))； 到期后的空档不满足该通道条件、重置持续时长，故障区间与证据不跨越空档。未配置的通道沿用「保持到下一样本」语义。 设置或清除后自动重新评估全部规则。

导入批次 / 撤销

文件或文本导入时，会为本批首次遇到的每个（设备、指标、时间戳）记录导入前快照； 同批重复键只快照一次、仍由最后一条有效值覆盖。仅最近一次且快照完整的批次允许撤销： 撤销会在同一事务中删除本批新增事件、恢复被覆盖事件的值 / 原始内容 / 原批次归属，再刷新故障； 任一步失败全部回滚。旧数据中无快照的批次不能撤销。

单通道突变恢复诊断

只读 · 读取事件与通道有效期，不重算故障
从已有通道选择设备与指标，输入 UTC 半开时间范围 [start, end)、正数跳变速率阈值（单位 / 秒）、 非负回归容差与正数观察时长（秒）。服务端按相邻有效样本的实际时间差计算变化速率； 采样有效期到期的空档切断连续性，不跨空档判突变，范围起点前仍有效的最近样本可作基线。 速率严格超过阈值时记下突变前基线，并在观察时长内寻找首个回到基线容差内的样本：找到为已恢复（给出恢复耗时）， 否则为未恢复（观察超时 / 有效期空档切断 / 范围结束）。已归属片段的样本不会重复开段。
时间在本机时区输入、按 UTC 查询；速率 = |Δ值| / 相邻样本实际秒数，严格大于阈值才判突变；回到基线容差按 |值 − 基线| ≤ 容差判定。
